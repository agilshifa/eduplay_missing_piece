EDUPLAY — MISSING PIECE (REVISI TERBARU)

CARA MENJALANKAN
1. Buka folder project ini di Visual Studio Code.
2. Buka index.html.
3. Klik kanan lalu pilih Open with Live Server.
4. Pastikan folder assets tetap berada di lokasi yang sama dengan index.html.

ISI PROJECT
- index.html
- style.css
- script.js
- assets/ (gambar objek lokal)

PERUBAHAN
- Informasi nyawa di halaman awal dihapus.
- Navigasi pindah halaman dan tombol suara dihapus.
- Perpindahan halaman hanya melalui alur Mulai Bermain -> Arena -> Rapor.
- Gambar objek dipusatkan dan layout dibuat responsif.
- Pilihan jawaban diacak terpisah dari urutan objek awal.
- Kartu statistik rapor tidak lagi menggunakan emoji.
- Koleksi objek lokal diperluas dan dipilih secara acak.
- Tetap menggunakan 15 ronde dengan 4, 6, dan 8 objek pada tiap tahap.

CATATAN
Rapor menunjukkan performa selama permainan, bukan diagnosis atau tes psikologi terstandar.
