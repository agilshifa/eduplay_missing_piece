EDUPLAY - MISSING PIECE
======================

CARA MENJALANKAN
1. Ekstrak folder eduplay_missing_piece.zip.
2. Buka folder eduplay_missing_piece di Visual Studio Code.
3. Buka file index.html.
4. Klik kanan pada index.html lalu pilih "Open with Live Server".
   Jika belum memiliki Live Server, install ekstensi "Live Server" di VS Code.
5. Alternatif: klik dua kali index.html untuk membukanya di browser.

STRUKTUR
- index.html : struktur halaman dan komponen website
- style.css  : desain dan responsivitas
- script.js  : alur permainan, 15 ronde, timer, skor, nyawa, dan rapor

CATATAN
- Versi ini menggunakan HTML, CSS, dan JavaScript murni.
- Permainan memiliki 15 ronde: 5 ronde per tahap.
- Jumlah objek: 4, 5, dan 6 sesuai tahap.
- Waktu pengamatan: 5 detik (tahap 1), 4 detik (tahap 2), 3 detik (tahap 3).
- Rapor merupakan ringkasan performa permainan, bukan diagnosis atau tes psikologi terstandar.
- Font Google membutuhkan koneksi internet; website tetap berjalan dengan font cadangan jika offline.
